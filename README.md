# 客户成功部-分贝通差旅看板

独立 GitHub Pages 看板，仅分析客户成功部差旅费用、差旅额度与交付出行覆盖。

不包含用车、回款或 ROI 数据，也不会修改渠道、智课整体或 AI 课堂看板。

## 数据口径

- 明细：`客户成功部分贝通明细`
- 额度：`差旅额度`
- 范围：2026 年 1–7 月
- 差旅类型：国内机票、火车、酒店
- 金额：企业支付净额，包含退款、退票等负向冲减
- 额度：1–4 月使用月度额度；5–7 月按 5–7 月季度额度除以 3 折算

## 管理视角

- 同时呈现部门整体额度执行与个人限制额度使用情况
- 分别识别超额、临界、月度突增和退款/退票关注人员
- 展示费用集中度与月度异常
- 将异常转化为带对象、证据、动作和状态的管理清单
